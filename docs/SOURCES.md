## 2. الأساس العلمي لفصل روايتي حفص وورش

عملاً بالمبدأ رقم (6) من خطة المشروع («الإتقان قبل الاتساع») وواقع الجزائر حيث تسود رواية ورش عن نافع:

1. **الفرق في عدّ الآي ورؤوس الآيات:**
   * في **حفص (العد الكوفي):** البسملة هي الآية رقم 1 في الفاتحة، وعدد آيات القرآن 6236 آية.
   * في **ورش (العد المدني الأخير):** البسملة ليست آية معدودة في الفاتحة (بل الآية 1 هي ﴿الحمد لله رب العالمين﴾)، والآية الأخيرة مقسومة إلى آيتين: ﴿صِرَاطَ الَّذِينَ أَنْعَمْتَ عَلَيْهِمْ﴾ (آية 6)، و﴿غَيْرِ الْمَغْضُوبِ عَلَيْهِمْ وَلَا الضَّالِّينَ﴾ (آية 7)، وإجمالي آيات القرآن 6214 آية.
2. **استحالة الدمج البرمجي:** أي محاولة لدمج صوت قارئ ورش مع ترقيم حفص أو العكس تؤدي إلى انزياح التظليل وخلل في تتبع الآيات. لذلك تم بناء مجموعتين مستقلتين تماماً في المشروع:
   * بيانات حفص: `public/data/hafs/{surah}.json`
   * بيانات ورش: `public/data/warsh/{surah}.json`

## 4. قائمة القرّاء الأولية ومصادر الصوت والتوقيت (الإصدار 1.0)

| القارئ | الرواية | المصدر المعتمد | ترخيص واستخدام الصوت | مصدر التوقيت وتزامن الآيات |
| :--- | :--- | :--- | :--- | :--- |
| **مشاري راشد العفاسي** | حفص عن عاصم | تسجيلات مجمع المصحف المرتل / Quranicaudio | ترخيص مجاني غير ربحي | واجهة Quran.com API v4 (توقيت بالمللي ثانية) |
| **محمود خليل الحصري** | حفص عن عاصم | الأرشيف الإذاعي المصري / وقف تراثي | ملكية عامة وتراث إسلامي متاح | واجهة Quran.com API v4 |

* **سياسة الاستضافة:** لا يتم الربط المباشر الساخن (hotlinking) بالخوادم الخارجية في الإصدار الإنتاجي، بل تُرفع الملفات الصوتية على تخزين كائنات مخصص مع CDN (مثل Cloudflare R2).

## 5. سكربت التحقق الآلي الصارم (`scripts/verify-text`)

يتم فحص وتأكيد سلامة الملفات عبر تشغيل الأمر:
```bash
npm run verify-text
# أو مباشرة:
./scripts/verify-text
```

### معايير التوقف التلقائي:
* إذا اختلف أي بايت أو حركة في الملفات المصدرية، يفشل السكربت ويخرج فوراً بكود خطأ `1`.
* يتم تشغيل الفحص قبل أي عملية بناء للموقع (`prebuild` hook في `package.json`).
* تمنع إعدادات النشر المستمر (CI/CD) إطلاق أي نسخة إذا لم يمر الفحص بنجاح 100%.
