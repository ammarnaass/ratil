# ﴿وَرَتِّلِ الْقُرْآنَ تَرْتِيلًا﴾ — رتل (Ratil)

> **مشروع ومشغّل تلاوات القرآن الكريم مع تتبع الآية وعرض النص القرآني المعتمد**  
> *«الرؤية: نظام موثوق لنص ديني حسّاس يحمله مشغّل صوتي سريع وبسيط. الوعد الذي يحمله الاسم هو التأنّي والإتقان، لا السرعة والحشو.»*

---

## المبادئ الحاكمة للمشروع (غير قابلة للتفاوض)

1. **سلامة النص القرآني:** لا يُكتب ولا يُعدَّل النص يدوياً؛ يُستورد حصراً من مصادر معتمدة ويُتحقق من بصمته الرقمية (`SHA-256`) آلياً عند كل بناء.
2. **أمانة الصوت:** لا صوت إلا بمصدر وإذن موثّقين، وخالٍ تماماً من التلاوات المولّدة بالذكاء الاصطناعي.
3. **الخصوصية التامة:** لا إعلانات، لا تتبع شخصي، ولا جمع لبيانات المستخدمين.
4. **السرعة الفائقة:** الزر الأول يعمل خلال ثانيتين كحد أقصى (≤ 2 ثانية حتى على شبكات 3G).
5. **المراجعة العلمية:** كل بلاغ عن خطأ يُراجع علمياً ولا يُطبَّق تلقائياً أبداً.
6. **الإتقان قبل الاتساع:** قراء أقل بتوثيق كامل وتزامن دقيق أفضل من قراء كثر بلا توثيق.
7. **احترام الروايات القرآنية:** فصل كامل ومستقل لروايتي **حفص عن عاصم** و**ورش عن نافع** (نصاً وتوقيتاً وعدّ آيات).

## هيكل المستودع (Repository Architecture)

```text
ratil/
├── data/
│   ├── source/               # النصوص الخام من المصادر المعتمدة (للقراءة فقط)
│   │   ├── quran-uthmani-hafs.txt     # نص حفص المعتمد (مشروع تنزيل Tanzil v1.1)
│   │   └── quran-uthmani-warsh.json   # نص ورش المعتمد (مجمع الملك فهد KFGQPC v10)
│   └── checksums.json        # البصمات المرجعية لجميع الملفات والخطوط
├── docs/
│   ├── NAMING_AND_DOMAIN.md  # ملف دراسة الاسم والنطاقات وحماية العلامة التجارية
│   └── SOURCES.md            # سجل المصادر المعتمدة والتراخيص والروايات
├── public/
│   ├── audio-manifest/       # فهرس القرّاء والتراخيص
│   │   └── reciters.json
│   ├── data/                 # ملفات JSON المولدة والمفهرسة للويب
│   │   ├── hafs/             # 114 سورة برواية حفص
│   │   ├── warsh/            # 114 سورة برواية ورش
│   │   ├── surahs.json       # فهرس السور الـ 114
│   │   ├── search_index_hafs.json
│   │   └── search_index_warsh.json
│   └── fonts/                # الخطوط العثمانية المعتمدة بصيغة WOFF2
│       ├── hafs.woff2        # خط مجمع الملك فهد لحفص
│       └── warsh.woff2       # خط مجمع الملك فهد لورش
├── scripts/
│   ├── verify-text           # سكربت التحقق الصارم من البصمات (يفشل البناء فوراً عند أي اختلاف)
│   ├── build-data            # معالجة النصوص وتوليد الفهارس
│   └── normalize-text.js     # خوارزمية تطبيع البحث القرآني
├── tests/
│   └── test-suite.js         # حزمة الاختبارات الآلية الشاملة
└── package.json
```

## الأوامر الأساسية

### 1. التحقق من البصمات الرقمية وسلامة النصوص:
```bash
npm run verify-text
# أو مباشرة
./scripts/verify-text
```

### 2. إعادة بناء البيانات وفهارس البحث:
```bash
npm run build-data
# أو مباشرة
./scripts/build-data
```

### 3. تشغيل حزمة الاختبارات الآلية:
```bash
npm test
```
