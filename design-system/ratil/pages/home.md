# شاشة الصفحة الرئيسية (Home Page Spec)

**الملف المرجعي:** `stitch-screens/05_home_desktop.html` و `stitch-screens/03_home_mobile.html`  
**المعرفات:** `e016b21e00ad44a7b1021fa5936f2bd9` (كمبيوتر) و `58d8e75a787944ed949346279a61470d` (جوال)

## مكونات الصفحة

1. **الترويسة التفاعلية (Navbar):**
   - شعار «رَتِّلْ» مع شارة المويجة الصوتية المتوهجة `graphic_eq` ونقطة الزمرد النابضة.
   - روابط التنقل (ديسكتوب): الرئيسية، تصفح المصحف، القرّاء، المحفوظات.
   - شارة الإنجاز المستمر (Streak): مثل «٧ أيام» مع أيقونة اللهب الزمردي.
   - زر تبديل الوضع الليلي/النهاري `dark_mode`.
   - زر الحساب / الدخول الشخصي.

2. **بطاقة الاستئناف البارزة (Spotlight Continue Listening Hero):**
   - مؤشر استئناف متحرك بنابض زمردي `animate-pulse`.
   - اسم السورة بخط عريض واضح `font-headline-lg`.
   - اسم الشيخ مع الرواية المعتمدة (ورش عن نافع / حفص عن عاصم).
   - مؤشر الآية التي توقف عندها المستخدم مع رقم الجزء.
   - شريط تقدم زمني مع الوقت المنقضي، النسبة المئوية، والوقت المتبقي.
   - زر تشغيل فوري دائري بارز بحجم 64px مع توهج زمردي خفيف `shadow-[0_0_24px_rgba(62,207,178,0.25)]`.
   - زر إضافي «فتح المصحف عند الآية».

3. **حقل البحث المركزي الموحد:**
   - شريط بحث عريض 52px بحواف دائرية `rounded-2xl`.
   - شارة اختصار لوحة المفاتيح `Ctrl + K`.
   - يدعم البحث بالاسم، الرقم (18)، المعرب (Kahf)، أو نص الآيات.
   - شرائح السور الأكثر طلباً أسفل شريط البحث (الكهف، الملك، الرحمن، يس، البقرة، الواقعة).

4. **شبكة السور (Surah Grid):**
   - بطاقات تفاعلية تعرض: رقم السورة، اسمها، نوعها (مكية/مدنية)، وعدد الآيات.
   - تأثير تحويم جذاب مع زر تشغيل سريع بنقرة واحدة.
